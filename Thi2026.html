Hướng Dẫn Upload Web Lên GitHub Pages Miễn Phí

Bước 1: Tạo Repository Đăng nhập GitHub, tạo kho lưu trữ mới (ví dụ: thi-trac-nghiem) chế độ Public.
Bước 2: Upload File Tải file mã nguồn này lên repo và đổi tên thành index.html. Bấm Commit changes.
Bước 3: Bật GitHub Pages Vào Settings → Pages → Mục Source chọn branch main (hoặc master) → Save.
Bước 4: Sử Dụng Web Chờ 1 phút, GitHub sẽ cấp đường link dạng: https://username.github.io/thi-trac-nghiem
